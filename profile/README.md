# icelib

Open-source developer tools and libraries by [ice breaker](https://icebreaker.top/).

## Projects

| Project | What it does | Docs |
| --- | --- | --- |
| [repoctl](https://github.com/icelib/repoctl) | Create, maintain, and release pnpm and Turborepo monorepos. | [Docs](https://repo.icebreaker.top/) |
| [mokup](https://github.com/icelib/mokup) | File-based API mocks for development and tests. | [Docs](https://mokup.icebreaker.top/) |
| [iconctl](https://github.com/icelib/iconctl) | Turn Figma icons and local SVGs into Iconify collections. | [Docs](https://iconctl.icebreaker.top/) |
| [postcss-plugins](https://github.com/icelib/postcss-plugins) | CSS unit conversion and responsive styling with PostCSS. | [Docs](https://postcss.icebreaker.top/) |
| [modern-ahocorasick](https://github.com/icelib/modern-ahocorasick) | Unicode-aware keyword matching for JavaScript and TypeScript. | [Docs](https://aho.icebreaker.top/) |
| [javachanges](https://github.com/icelib/javachanges) | Changeset-based versioning and releases for Maven and Gradle. | [Docs](https://javachanges.icebreaker.top/) |
